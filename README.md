# DJayJesse

Dark-mode storyboard and comic showcase built with Angular, TypeScript, Tailwind CSS, and Vitest.

## Quick Start

```bash
npm install
npm start
```

Open `http://localhost:5173` in your browser.

## Scripts

- `npm start` / `npm run dev` — Start local Vite dev server
- `npm run build` — Type-check and build production bundle (`dist/`)
- `npm test` — Run unit and component tests (Vitest)
- `npm run test:coverage` — Run tests with coverage (`coverage/lcov.info`)
- `npm run test:e2e` — Run browser E2E tests (Playwright)
- `npm run lint` — Run ESLint
- `npm run format` — Format files with Prettier
